# V3DRender 0.23

Imported memory now follows pages that RISC OS moves. V3DRender listens
for Service_PagesUnsafe/PagesSafe (and the 64-bit forms): the GPU waits
while imported pages move, then its page tables point at their new
places. Before, the GPU could go on writing pages that had been given to
something else. This is the likely cause of the web browser's broken GPU
drawing and hangs. Also: everything up to 0.22.
