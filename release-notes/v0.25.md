# V3DRender 0.25

- Freed GPU memory is kept for reuse, up to 16 MB, while a program has the
  GPU open. New buffers that fit use it without asking RISC OS for memory.
  This makes buffer creation cheaper for the web browser's textures, and
  RISC OS has to move fewer other programs' pages. `*V3DRender pool <MB>`
  sets the limit; `*V3DRender` shows how much is kept and what buffer
  creation costs.
- New buffers are zeroed in bursts, faster on uncached memory.
- Everything up to 0.24: start-up breadcrumbs (`V3DRender$Step`), imported
  memory that follows pages the OS moves, power domain first at start-up,
  hardware facts for Configure's RISC3D window.
