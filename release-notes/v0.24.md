# V3DRender 0.24

- Start-up records how far it got in `V3DRender$Step` (ending "ready"),
  for machines that stop at start-up.
- A start-up that fails part way is undone safely, and the interrupt
  handler never runs before the GPU is set up or calls a null routine.
- Everything up to 0.23: imported memory follows pages the OS moves,
  power domain first at start-up, hardware facts for Configure's RISC3D
  window.
