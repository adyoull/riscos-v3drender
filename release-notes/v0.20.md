# V3DRender 0.20

- **Configure's RISC3D window can show the GPU's hardware** (RISC3D 0.09's
  reason 4): GPU and revision, clock, GPU memory, largest image (4096 x
  4096), desktop 2D. The GL versions come from riscos-mesa's GPUProbe.
- **Safer start-up:** the firmware's V3D power domain is turned on before
  any V3D register is read. This is a likely cause of "Internal abort" at
  start-up on a Compute Module 4.
