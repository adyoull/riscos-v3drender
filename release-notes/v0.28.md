# V3DRender 0.28

- The desktop's 2D on the GPU can be turned on and off from Configure's
  RISC3D window (RISC3D 0.10 and !RISC3DSetup 1.07), through driver reason 5.
  `*V3DRender 2D` and the window share one path, so they always agree.
- `*V3DRender 2D on` reports an error if it couldn't start.

Everything in 0.27 is included (the start-up log and diagnostic options).
