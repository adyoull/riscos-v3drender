# V3DRender 0.31

- **New: `DRM_IOCTL_RISCOS_PRESENT`** (`'R'`, nr 4): the GPU copies a 3D program's finished frame to the screen, rectangle by rectangle. It is for EGL's swap in a desktop window, where the CPU did this before.

  ```c
  struct drm_riscos_present_rect { __s32 dst_x, dst_y, width, height, src_x, src_y; };
  struct drm_riscos_present {
    __u32 handle, format, flags;     /* flags: SRC_UIF 1, VSYNC 2, SRC_UIF_XOR 4 */
    __u32 width, height;             /* the source's */
    __u32 uif_height_or_stride;      /* UIF: padded height in rows; raster: bytes a row */
    __u32 rect_count, pad;           /* up to 256 rectangles; pad 0 */
    __u64 rects;
    __u32 in_sync, out_sync;
  };
  ```

- **Sources:** ABGR8888, XBGR8888, ARGB8888, XRGB8888 and RGB565, raster or UIF.
- **Screens:**
  - 16 million colours, in RGB or BGR order, with or without alpha;
  - 64K colours (5:6:5) and 32K colours (1:5:5:5), each in either order.
  - Others refused (-EINVAL).
- **Where it draws:** the screen is read on every call: the mode, and the bank the VDU writes to.
- **Rectangles** are clipped to the screen and the source.
- **Vertical sync:** not offered. The VSYNC flag gives -EOPNOTSUPP.
- **Probing:**
  - A call with no rectangles tests the screen.
  - -ENOTTY means not offered: older V3DRender, and ROL.
- **Desktop 2D:** doesn't depend on it. PRESENT works with RISC3D's desktop 2D switch off.
- **`*V3DRender`** shows a "Presents:" line.

Not yet tested on a Pi: this release is for MESA's EGL work.

Everything in 0.30 is included.
