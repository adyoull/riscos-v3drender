# V3DRender 0.21

While any program has the GPU open, the desktop's 2D copies and fills
now stay on the CPU. A web browser's GPU drawing went wrong with
`*V3DRender 2D on` beside it (render jobs hung and frames were lost); the
cause is still being looked for. `*V3DRender 2D alongside on` allows 2D
beside programs again, for testing. Also in 0.21: everything from 0.20
(reason 4 for Configure's RISC3D window, power domain first at start-up).
