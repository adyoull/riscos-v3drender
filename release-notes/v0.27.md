# V3DRender 0.27

For finding start-up problems (a CM4 that stops at boot with !RISC3D):

- `Log <file>` (or `V3DRender$Log`): each start-up step is added to a text
  file as it begins, closed each time so it survives a crash, with the
  options, the RAM, HAL_IRQClear's address, any error and the first GPU
  interrupt.
- `NoIRQ`: the GPU's interrupt isn't claimed; waits poll the GPU instead.
- `NoRISC3D`: not registered with RISC3D.
- `LowMem`: no memory asked for above 1 GB.

Everything in 0.26 is included.
