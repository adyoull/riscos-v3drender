# V3DRender 0.18

Faster desktop 2D (still off by default; `*V3DRender 2D on`):

- The GPU command lists for copies and fills are written a word at a
  time, a quarter as many writes to the uncached buffer.
- A program flipping between two screen banks no longer makes the next
  copy re-read the screen: only the bank's address changes.
- `*V3DRender 2D limits [5 numbers]` sets the sizes below which the CPU
  does the work (no numbers: Rob's).

Kit 21's Desk2D adds timings for small copies and fills with the limits
off, to find where the GPU starts to win.

Not yet run on a Pi: please run kit 21's Check and Desk2D.
